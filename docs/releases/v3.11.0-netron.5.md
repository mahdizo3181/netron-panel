## 🛟 In-place conversion of a stock 3x-ui, with rollback

Already running stock 3x-ui? Run the install command on that server and it is converted to netron-panel in place.

- 💾 **Backup first** — the database, config and TLS material are copied to `/root/xui-backup-<time>/` with owner-only permissions (they contain tokens and keys).
- ✅ **Health check, then automatic rollback** if the converted panel does not come up healthy.
- ↩️ **`x-ui rollback`** to go back to stock later. The database migration itself is one-way, so keep the backup.
- 🛡️ **Interruption-safe** — HUP/INT/TERM are ignored during the destructive window, and a marker lets a killed run recover itself on the next start.
- 🚫 **Refuses instead of guessing** — Docker, PostgreSQL, partial installs and too-old versions are rejected unchanged (`--force-old` overrides the version check).
- 🔁 Existing `install.sh`, `update.sh` and the `x-ui` menu hand stock installs over to the converter automatically.
- 🧪 Tested with stock database fixtures and a lossless-migration test.

After converting, the multiplier switch is OFF; enable it in Settings when your nodes are ready (nodes first, then master).

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mahdizo3181/netron-panel/main/install.sh)
```

Details: [docs/UPGRADE_FROM_STOCK.md](https://github.com/mahdizo3181/netron-panel/blob/main/docs/UPGRADE_FROM_STOCK.md)

> [!WARNING]
> Never run the stock upstream installer or updater on a netron server.

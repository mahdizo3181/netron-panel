## 🔒 Multiplier field lock and Restart Panel fix

- 🔒 **Multiplier field locked while the feature is off** — the inbound form's usage multiplier field and its x1 / x1.2 / x1.5 / x2 chips are greyed out while Settings → "Enable per-inbound multiplier" is OFF, for every protocol, with a hint pointing to Settings. Opening and saving an inbound while it is locked never changes its stored value, and the form reads the saved switch fresh each time it opens.
- 🔁 **Restart Panel now applies the multiplier mode** — before, only Restart Xray did; a panel-only restart left `config.json` with plain emails. A panel restart now restarts Xray only when the saved mode differs from the running one, so ordinary restarts do not drop connections. An Xray you stopped by hand stays stopped.
- 🧹 **No more amber "restart Xray" banner** on the Settings page — the generic restart notice remains, and the "Saved: on/off · Running: on/off" line stays.
- ⚠️ **Known:** Discord `!restart` does not apply the saved mode yet; use the panel's Restart Panel or Restart Xray.

### Update

If your panel did not offer this update, update from the server's shell:

```bash
x-ui update
```

> [!WARNING]
> Never run the stock upstream installer or updater on a netron server.

## 🚀 First netron-panel release: per-inbound usage multiplier on 3x-ui v3.11.0

netron-panel is a fork of [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) (base `v3.11.0`). This is the first release that installs from this repository and bills traffic per inbound.

- ⚖️ **Per-inbound multiplier, one shared quota** — give each inbound its own ×0–×10 factor (e.g. `direct ×1`, `tunnel ×1.2`). Real bytes × the inbound's factor are added to the client's single quota. Quota cut-off, expiry, panel numbers, bot reports and the `Subscription-Userinfo` header all show the weighted number. Subscription links and clients stay unchanged.
- 🔒 **Safe by default** — the mode sits behind **Settings → Enable per-inbound multiplier**, OFF by default (stock behaviour). It goes live on the next forced Xray restart.
- 🌐 **Multi-node aware** — each node bills its own traffic and the master never multiplies it twice; the master warns about nodes that are old or have the mode off.
- 📊 **Real and billed bytes per inbound** are stored side by side; inbound totals stay real bytes.
- 🔗 **Info config for Happ** — the dummy info/expired/depleted entry in subscriptions is now a non-functional VLESS link, because newer Happ versions reject SOCKS entries. The old SOCKS entry is one setting away.
- 📦 **Installer and updater point at this repo** — `install.sh`, `update.sh`, the `x-ui` menu and the panel's Update button fetch netron releases (linux `amd64`/`arm64`, with `.sha256`).

### Install

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mahdizo3181/netron-panel/main/install.sh) v3.11.0-netron.3
```

> [!WARNING]
> Never run the stock upstream installer or updater on a netron server: it replaces the binary with stock 3x-ui, which bills every inbound at ×1.
